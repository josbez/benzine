# Exact versions, deliberately. With lower bounds only, every CI run
# installed whatever had been released that morning: the weekly backtest
# broke on a scikit-learn release whose SimpleImputer had picked up a new
# `keep_empty_features` default, and nothing in this repository had
# changed. A daily job on a moving dependency set is a build that fails on
# days you did not touch it.
#
# Dependabot raises these (see .github/dependabot.yml) and the test suite
# runs on the proposed version before it is merged, which is the same
# freshness with the failure moved into a pull request.
#
# Only the direct dependencies are pinned, not the full transitive tree. A
# pip-compile lock would close the remaining gap (scipy, joblib) at the
# cost of a toolchain to regenerate it; the breakages seen so far have all
# been in this list.
